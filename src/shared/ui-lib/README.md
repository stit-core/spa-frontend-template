# shared/ui-lib

**Дисциплина gap-шимов**: сюда кладутся только временные обёртки/реализации тех
UI-примитивов, которых **сейчас не хватает** в `@sftbmb/ui`. Цель — чтобы
проект не писал свои самописные кнопки/инпуты, а оставлял явный долг к DS.

## Правила

1. Каждый шим — папка с компонентом + `index.ts`.
2. Каждый шим обязан иметь запись в [`docs/ui-lib-gaps.md`](../../../docs/ui-lib-gaps.md)
   с описанием gap'а, ссылкой на тикет в ui-lib и критериями замены.
3. Импорт шима — через `@/shared/ui-lib/<name>`, **не** через `@/shared/ui`.
4. Когда фича появляется в `@sftbmb/ui` — шим удаляется одним движением,
   все импорты массово меняются на `@sftbmb/ui`. Запись в `ui-lib-gaps.md`
   тоже удаляется (forward-only).

## Антипаттерны

- ❌ Кастомизация дизайна «потому что так красивее» — это не gap, это кастом → в `shared/ui/` (обёртка над DS).
- ❌ Шим без записи в `docs/ui-lib-gaps.md` — теряем учёт долга.
- ❌ Шим, развитый «слишком хорошо» — растёт ad-hoc дизайн-система рядом с настоящей.

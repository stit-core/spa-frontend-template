# Skill: smartdev (cockpit сессии)

Отвечает на «где я и что дальше»: собирает состояние и называет один следующий
шаг. Файлы не правит, вопросов не задаёт (это сводка, не интервью) и `pnpm check`
не запускает — гейт тяжёлый, его гоняют перед claim «готово» или push.

## Что показать

1. **Git**: `git status --short`, `git log -3 --oneline`, расхождение с `origin/main`.
2. **Активные планы**: `pnpm plan:check --summary` — план, статус, прогресс и следующий
   шаг; активный план прочитай целиком, начиная с «Где мы сейчас».
3. **Развёрнут ли форк**: `package.json#name` всё ещё `@stit/spa-frontend-template`
   и reference-слайсы на месте (`src/features/auth`, `src/pages/profile.tsx`,
   `src/pages/todos.tsx`, `src/features/theme`) — форк не развёрнут.
4. **Артефакты**: все ли `docs/stack/*.md` в `status: stable`; заведена ли FSD-карта
   поверхности в `<strategy-path>/docs/projects/<slug>/fsd/<surface>/` (резолв —
   поля в `docs/stack/service.md`, дефолт `../strategy`).
5. **Blocker'ы**: `(**blocker**)` в `.claude/skills/stack-deep-dive/state/`.
6. **Гейт**: есть незакоммиченные правки — напомнить, что перед claim «готово»
   нужен `pnpm check`.

## Следующий шаг

Один, конкретный:

- есть задача (от юзера или из хаба `<org>/infra`) → содержательное изменение
  через `/plan`, truly-atomic правка или багфикс — сразу;
- форк не развёрнут → `/init-service`;
- есть активный план → продолжать его;
- открыт blocker → закрыть его в `/stack-deep-dive`;
- всё чисто → ждать запроса юзера.

## Формат вывода

Компактная сводка, строка на пункт — например:

```
ветка: feature/login (5 коммитов сверх origin/main, дерево чистое)
план: «Реализовать /reset-password» — шаг 2 из 4
шаблон: развёрнут (reference-слайсы убраны)
артефакты: docs/stack 8/8 stable; FSD-карта ../strategy/…/fsd/web/ заведена
следующий шаг: продолжить план через /plan
```
